# Object-Oriented Programming (OOP) - 2nd Semester

This repository contains practical exercises, midterm exams, and evidence portfolios developed during the second semester for the Object-Oriented Programming course.

---

## Contents

* Practical Exercises: Course exercise solutions (`Ej12.html`, `Ej13.html`, `Ej14.html`).
* Midterm Exams: Practical evaluations for the first and second terms (`Examenparcial1.html`, `Examenparcial2.html`).
* Evidence Portfolios: Cumulative portfolios submitted throughout the semester (`Portafolio1_Johnston.html`, `Portafolio2_Johnston.html`, `Portafolio3_Johnston.html`, `Portafolio4_Johnston.html`).

---

## Technologies and Concepts

* Technologies: HTML5 / JavaScript.
* Core Concepts: Object-Oriented Programming (Classes, Objects, Inheritance, Encapsulation, Polymorphism).
